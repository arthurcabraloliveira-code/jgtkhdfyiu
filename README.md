
# Calculadora de Media Escolar

## Descricao do Projeto

Este projeto consiste em um programa desenvolvido em Python
para calcular a media final de um aluno com base em quatro notas.

O programa solicita o nome do aluno e suas notas, calcula a
media aritmetica e apresenta a situacao final: aprovado,
recuperacao ou reprovado.

## Objetivo

Praticar os conceitos fundamentais da linguagem Python,
incluindo entrada de dados, variaveis, operacoes matematicas,
estruturas condicionais e exibicao de resultados.

## Funcionalidades

- Solicitar o nome do aluno.
- Receber quatro notas.
- Calcular a media aritmetica.
- Exibir a media final.
- Informar se o aluno foi aprovado, esta de recuperacao
  ou foi reprovado.

## Tecnologias Utilizadas

- Python 3
- GitHub
- Markdown

## Requisitos

- Ter o Python 3 instalado no computador.

## Como Executar

1. Baixe ou clone este repositorio.
2. Abra um terminal na pasta do projeto.
3. Execute o comando:

   python script.py

4. Informe o nome do aluno e as quatro notas solicitadas.
5. Consulte a media final e a situacao apresentada.

## Regra de Calculo

A media e calculada somando as quatro notas e dividindo
o resultado por quatro.

- Media maior ou igual a 7: Aprovado.
- Media maior ou igual a 5 e menor que 7: Recuperacao.
- Media menor que 5: Reprovado.
